# doc/ —— readme.md 的正文来源

仓库根目录的 **`readme.md` 是生成产物**，正文按小节拆在本目录下。
这样做的原因：合并后的 readme 有 2000+ 行，单文件不利于分工编写 ——
拆成 33 个 20~180 行的小文件后，一次只需要改（或让 AI 改）其中一个。

## 目录约定

```
doc/
├── README.md                本文件（不参与合并：文件名不以两位数字开头）
├── build_readme.py           合并脚本
├── 00-intro.md               正文第 1 块
├── 01-what-is-this.md
├── ...
├── 18-01-swd-throughput.md   「第 18 部分」再分子块时用 NN-MM 命名
├── ...
└── 22-references.md          正文最后一块
```

**文件名的两位数字前缀决定正文顺序**（按文件名排序拼接）。`NN-slug.md` 是一个小节，
`NN-MM-slug.md` 是某一节内部的子块（如性能实测的 18.1~18.7）。

不匹配 `NN-*.md` 的文件（本文件、脚本等）一律不参与合并。

## 工作流

```powershell
# 1. 改 doc/ 下对应的小文件
# 2. 合并回 readme.md
xmake doc                       # 或：python doc/build_readme.py

# 只校验 readme.md 是否与 doc/ 同步（CI / 提交前用；不同步时退出码非 0）
xmake doc --check               # 或：python doc/build_readme.py --check

# 看看有哪些文件、各多少行
xmake doc --list                # 或：python doc/build_readme.py --list
```

`xmake doc` 只是包了一层 `python doc/build_readme.py`（自动挑选 python 解释器并按
仓库根定位脚本）。没装 xmake 或想直接用 python 时，用左边的 python 命令即可，
两者等价。

> 在**仓库根目录**运行 `xmake doc`。xmake 会从当前目录向上找 `xmake.lua`，
> 所以从 `firmware/` 等子目录里跑也能命中；但 `xmake -P <仓库根> doc` 这种写法
> 会把 `doc` 当成 target 名而报错，不要用。

**不要直接改 readme.md** —— 下次合并会覆盖掉。要改内容就改 `doc/`。

## 编辑约定

- **每个文件以自己的标题行开头**（如 `## 5. 快速开始`）。
- 属于「第 N 部分」的**第一个**文件，把该部分的一级标题（`# 第N部分：…`）也放在
  文件最前面 —— 这样合并后部分标题与它的第一节之间不会多出一条 `---`。
- **每两个文件之间由脚本插入一条 `---`**；文件内部如果还要分隔子块，自己写 `---`
  （会被原样保留）。
- **章节编号写在标题里，脚本不维护编号**。插入/删除小节后要手工把后续标题的编号顺移。
- **交叉引用一律写标题，不要写章节号**（用「见『撤除波特率上限之后』」而不是
  「见 16.4 节」）—— 否则重编号后引用就失效了。
- 行尾风格沿用现有文件（CRLF），脚本合并时保持一致。

## 新增一个小节

1. 在 `doc/` 下按顺序命名新文件，例如插在 `05-quick-start.md` 之后就是
   `06-<新组名>.md`。
2. 把该位置之后的所有文件**按顺序重命名**（数字前缀要连续，否则顺序会被打乱）。
3. 把后续所有标题里的章节编号手工 +1。
4. 在 readme.md 顶部没有目录（用的是 `[TOC]` 标记，由编辑器插件渲染），无需手工维护。
5. 跑 `python doc/build_readme.py`。

> 说明：脚本刻意保持「只拼接、不改内容」——不解析标题、也不重排编号。
> 编号的正确性由编辑时保证，这样任何一次合并都可以逐字节复现。

## 拆分历史

`doc/` 下的 33 个文件由根 readme.md 一次性拆分而来（2026-10-13）。拆分同时修掉了
上一轮合并留下的两个缺陷：`## 4. 功能特性`、`## 5. 快速开始` 两个标题被漏掉，
导致那两节的内容挂在「技术栈」下面；补上之后原 `## 4.`~`## 20.` 顺移 +2，
最终成为 `## 1.`~`## 22.`。拆分经过校验：正文非空行逐行完全一致（1470 行）。
